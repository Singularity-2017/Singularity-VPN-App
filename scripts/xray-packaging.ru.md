# Упаковка Xray без скачивания

Сборка из ранее проверенных официальных файлов Windows x64 Xray 26.10.31:

```powershell
./scripts/build.ps1 -Setup -XraySource C:/verified/xray-26.10.31
```

Без `-XraySource` используется `local/xray`. Сборки службы или окна требуют
эти файлы и без `-Setup`. Скачивания и поиска в PATH нет. Файл
`internal/xraybundle/pins.json` закрепляет digest официального архива и хеш
каждого копируемого файла. Подготовка отклоняет отсутствующие или изменённые
файлы до замены каталога назначения и копирует только разрешённый список.

Путь исполнения: `<каталог исполняемого файла службы>/xray/xray.exe`, рядом
`wintun.dll`, `geoip.dat` и `geosite.dat`. LICENSE, LICENSE-Wintun и README.md
копируются без изменений. NOTICE.txt содержит ссылку на точную версию исходников,
manifest.json — происхождение файлов. Подписывать или изменять официальные
бинарники нельзя: это нарушает закреплённые хеши. Служба управляет процессом
и освобождает Xray и DLL до сообщения об окончательной остановке.

Установщик содержит доверенные хеши внутри себя и проверяет Xray до остановки
службы. Подмена manifest.json на диске не разрешает новый бинарник. Используется
существующий защищённый каталог Program Files и атомарная замена отдельных файлов.
Обновление заменяет весь обязательный комплект и удаляет устаревшие зависимости;
удаление приложения очищает весь каталог xray. Замена всего комплекта не является
единой транзакцией; сохраняется существующее восстановление запуска службы.

Для обновления зависимости сначала проверяется официальный архив принятым
способом, сверяются извлечённые файлы и лицензии, затем явно меняются закреплённые
хеши. Сборка никогда не вычисляет доверенные хеши из произвольного каталога.
Конфигурациям и учётным данным pilot в установщике места нет.

Встроенный полный туннель разрешает имена через DoH с `UseIPv4`. IPv6
захватывается TUN и блокируется, а не уходит через физический интерфейс: это
исключает выбор локально принятого IPv6-соединения, недоступного с ноды.
Проверка соединения требует доверенного TLS-ответа через сокет, привязанный
к TUN. Настройки внешних экспортов определяются их клиентами.
