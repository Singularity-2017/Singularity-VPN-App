# Issue tracker: Gitea

Issues for this repository live in the self-hosted Gitea instance, in
`Singularity/Singularity-VPN-App`.

This is the source of truth. GitHub is only a mirror for published copies --
do not open issues there, and do not assume `gh` points at this project.

Issues about the control plane -- the HTTP API, the portal, the nodes --
belong to the `Singularity-VPN` repository instead, not to this one.

## When a skill says "publish to the issue tracker"

Create an issue in the Gitea repository above (web UI, or the Gitea API with
a token).

## When a skill says "fetch the relevant ticket"

Open the issue in the Gitea repository and read it together with its comments.
