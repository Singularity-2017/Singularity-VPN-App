# Экспорт профиля VLESS

[English version](vless-export.md)

Откройте Аккаунт → Профиль → VLESS рядом с существующим профилем. Выберите
«Создать и скачать VLESS» для доступного сервера и место сохранения в системном
диалоге. Текстовый файл содержит один URI VLESS для импорта в совместимый клиент.
Отмена диалога не отправляет запрос экспорта.

Действие создаёт альтернативную конфигурацию существующего профиля,
материализованного на сервере. Новый слот аккаунта не создаётся; выбранный
профиль и туннель не меняются. Адаптер VLESS в приложение не добавляется.

Служба использует авторизованный токен устройства для запросов:

- `GET /api/v1/vpn/vless/options?client_id=...` с ответом
  `data.nodes[{node_id,vless_available,reason}]`.
- `GET /api/v1/vpn/config?client_id=...&node_id=...&protocol=vless&mode=vpn`
  с ответом `data{config,protocol,mode,expires_at}`.

Скачивание разрешает только явное логическое `vless_available: true`.
Доступность повторно проверяется перед выдачей. Недоступные узлы, отсутствующие
поля, ошибки и старые серверы запрещают экспорт. Backend проверяет владельца,
активность, материализацию профиля и готовность helper. Приложение проверяет
протокол, режим и единственный URI в ответе. Конфигурация проходит через
авторизованный канал службы к системному сохранению, минуя WebView и DOM.

Тесты используют искусственные HTTP-, service- и browser-fixtures: профили в
рабочем окружении не создаются, действующий туннель не меняется.
